## ✅ Best Practices

### Structure & Organization
- **Repeat questions** in your notebook to help us navigate
- **Be consistent** in your formatting throughout
- **Split your code** according to questions/sub-questions (don't solve all exercises in one cell)
- **Control notebook length** - prioritize material and express yourself clearly and succinctly

### Visualizations
> **⚠️ IMPORTANT:** Format your plots properly!
> - Label all axes
> - Include descriptive titles
> - Add text explaining each figure
> - Comment on what information can be extracted from the visualizations

### Analysis & Writing
- **Avoid simple yes/no answers** - reflect on *why* and provide reasoning
- **Be precise and objective** - support observations with data and theory
- **Answer all parts** - read carefully and ensure you address all sub-questions
- **Add references** when introducing formulas, citing papers, or using external sources (follow academic standards)

### Code Quality
- **Keep code short and neat** - include only relevant code
- **Remove irrelevant output** - no unnecessary print statements or debugging code
- **Ensure code runs** - your notebook should execute without errors
